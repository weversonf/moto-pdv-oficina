# Moto PDV Oficina (ex PDV-G3)

PDV de oficina para motos. Nome novo proposto: **`moto-pdv-oficina`**.

## Executar
Abra `index.html` no navegador.

## Renomear no GitHub (preserva redirect)
1. GitHub > `weversonf/PDV-G3` > Settings > General > Repository name > `moto-pdv-oficina` > Rename
2. Local: `git remote set-url origin https://github.com/weversonf/moto-pdv-oficina.git`
3. Push desta branch depois do rename.

Nao mexi em nada de motel/moteis.
